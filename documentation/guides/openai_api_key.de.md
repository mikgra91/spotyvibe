---
title: OpenAI API-Schlüssel erstellen
subtitle: Ein kostenloses Entwicklerkonto, dann ein Klick, um einen Schlüssel zu erstellen.
---

## Step 1 — Registrieren oder anmelden
Gehe zu [platform.openai.com](https://platform.openai.com) und melde dich an (oder erstelle ein Konto, falls du noch keins hast — die Registrierung dauert etwa eine Minute).
![Bei OpenAI anmelden](/docs/guides/openai/step1_signin.png)

## Step 2 — API-Schlüssel-Seite öffnen
Klicke in der linken Seitenleiste auf **API keys**. Möglicherweise musst du zuerst deine Telefonnummer verifizieren — das ist eine Sicherheitsmaßnahme von OpenAI, keine SpotyVibe-Anforderung.
![API keys in der Seitenleiste](/docs/guides/openai/step2_sidebar.png)

## Step 3 — Neuen Schlüssel erstellen
Klicke auf **Create new secret key**, gib einen beliebigen Namen ein (z.B. `SpotyVibe`) und klicke Create. Kopiere den Schlüssel sofort — OpenAI zeigt ihn nicht noch einmal an.
![Neuen Schlüssel erstellen](/docs/guides/openai/step3_create.png)

## Step 4 — Schlüssel in SpotyVibe einfügen
Zurück in SpotyVibe: Öffne ☰ → **🔑 Zugangsdaten**, füge den Schlüssel in das Feld **OpenAI API Key** ein und klicke **Speichern**. Du siehst eine Bestätigung, dass der Schlüssel gespeichert wurde.
![Schlüssel in SpotyVibe einfügen](/docs/guides/openai/step4_paste.png)
